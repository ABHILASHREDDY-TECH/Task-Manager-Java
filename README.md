# Task Manager Application

A simple task management application built using Java Spring Boot and frontend technologies.

## Features

- Add task
- View all tasks
- Edit task
- Delete task
- Mark task as complete or incomplete
- Handles empty task title
- Handles non-existing task update/delete

## Tech Stack

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Java
- Spring Boot

Storage:
- In-memory ArrayList

## API Endpoints

GET /tasks  
POST /tasks  
PUT /tasks/{id}  
DELETE /tasks/{id}  
PATCH /tasks/{id}/toggle  

## How to Run

1. Open the project in Eclipse or IntelliJ.
2. Run TaskmanagerApplication.java.
3. Open frontend/index.html in browser.
4. Add, edit, delete, and mark tasks as complete.
